Every control can be changed in **Settings → Controls** (keyboard, a second key, mouse and controller columns).
Any Xbox-style controller works; button names below are Xbox ones.

<div class="table-scroll">

| Action | Keyboard | Controller |
|---|---|---|
| Move | Arrows or <kbd>A</kbd> <kbd>D</kbd> | D-pad or left stick |
| Jump (hold for higher) | <kbd>Space</kbd> / <kbd>Z</kbd> / <kbd>K</kbd> | <kbd>A</kbd> |
| Swing the pencil / headbutt | <kbd>J</kbd> / <kbd>C</kbd> / left-click | <kbd>X</kbd> |
| Roll | <kbd>X</kbd> / <kbd>L</kbd> | <kbd>B</kbd> |
| Dodge (roll with no direction held) | <kbd>X</kbd> / <kbd>L</kbd> | <kbd>B</kbd> |
| Dash (1.5 s cooldown) | <kbd>Shift</kbd> / right-click | <kbd>RB</kbd> |
| Slide | Down while running | D-pad down |
| Crouch / crawl | Hold down, then move | Hold D-pad down, then move |
| Drop through a plank | Down + Jump | Down + <kbd>A</kbd> |
| Back to the last flag | <kbd>R</kbd> | <kbd>Back</kbd> |
| Pause | <kbd>Esc</kbd> / <kbd>P</kbd> | <kbd>Start</kbd> |

</div>

**In cutscenes:** <kbd>Space</kbd> skips to the next line, <kbd>Esc</kbd> skips the scene.

## Two players

See [Co-op](/wiki/co-op) for who gets which controller. With no controllers at all, both players share the keyboard:

</div>

## Settings worth knowing

- **Assist mode** (Settings → Gameplay): 5 hearts instead of 3, the game runs a little slower, jumps are more
  forgiving and the dash recharges faster. Turn it on any time; nobody's judging. Well, the Narrator is, but he
  judges everything.
- **Narrator text speed**: slow, normal or fast.
- **Speedrun timer**: on or off.
- **Hand-drawn wobble** (Settings → Video): how much the lines boil. Turn it down if it bothers you.
- **Screen shake**, a separate volume for every kind of sound, display mode, resolution, VSync and an FPS limit.
